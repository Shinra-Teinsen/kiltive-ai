# agents/

Agents IA spécialisés, chacun avec un rôle précis plutôt qu'une seule IA généraliste
qui essaie de tout faire.

**Rempli à partir de :**
- Étape 14 — Agent Agronome (conseils de culture, RAG)
- Étape 15 — Agent Météo (interprétation intelligente des données météo)
- Étape 16 — Agent Diagnostic des maladies (vision IA)
- Étape 17 — Agent Marché (recommandations de prix/vente)

Chaque agent sera un module indépendant avec son propre prompt système, ses propres
outils, et sera orchestré depuis le backend.
